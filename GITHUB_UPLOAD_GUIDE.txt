GITHUB UPLOAD GUIDE
===================

1. Extract this ZIP on your computer.
2. Open your GitHub repository.
3. Upload everything INSIDE the extracted folder to the repository root.
4. Confirm that these paths exist on GitHub:

   .github/workflows/build-apk.yml
   Android_App/app/build.gradle.kts
   Android_App/settings.gradle.kts
   Windows_Agent/PriceMatcher.py

5. Commit the upload.
6. Open Actions > Build Android APK > Run workflow.
7. After it finishes, download PriceMatcher-Remote-APK from Artifacts.

IMPORTANT
---------
The .github folder may be hidden in Windows File Explorer. Uploading the full
extracted folder using GitHub Desktop or Git is the safest method. When using
the GitHub website, ensure .github/workflows/build-apk.yml appears after upload.

This workflow uses GitHub's Java 17 and Gradle 8.9 setup. Android Studio and a
local Gradle wrapper are not required for the GitHub build.
